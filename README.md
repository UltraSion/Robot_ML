# Robot_ML · 물리 기반 보행 학습

Unity ML-Agents를 활용한 물리 기반 보행 학습 프로젝트입니다. 로봇을 직접 움직이게 만드는 과정에서 강화학습과 물리 기반 관절 제어를 익히고자 시작했습니다.

- **개발 기간:** 2025.01 ~ 2025.08
- **사용 기술:** Unity, C#, ML-Agents, 물리 기반 관절 제어
- **구현 범위:** 프로젝트 설계 및 구현 전반

## 보행을 만들기 위해 시도한 것들

- **보상 설계:** 몸체 높이에서 시작해 자세·발 방향·이동 속도로 평가 기준 확장
- **힘 배분:** 전체 힘을 비율로 나누는 방식에서 관절별 힘 요청과 총량 제한으로 변경
- **접지 조건:** 모든 발이 지면에서 떨어지면 에피소드 종료
- **관절 구성:** 발 관절을 포함한 16개 관절에서 12개 관절로 단순화
- **출력 구조:** 관절별 각도 출력과 기준값·차이값 조합 실험
- **학습 환경:** 무작위 지형, 외부 충격, 학습 성과에 따른 목표 속도 증가 적용

## 회고

처음에는 로봇 슈팅 게임을 만들려고 포탑과 작살도 구현했습니다. 총을 쏘기 전에 걷는 법부터 가르치다 보니, 프로젝트는 어느새 보행 연구가 됐습니다.

사람처럼 걷는 로봇을 원했지만 좀비가 나왔고, 드라군을 원했지만 개구리가 나왔습니다.

“파라미터 하나만 바꾸면 될 것 같은데…?”라는 생각으로 실험을 이어갔습니다. 기록과 커밋을 미룬 채 몇 달이 흘렀고, 한 번에 10시간씩 걸리는 학습 때문에 개선을 빠르게 반복하기도 어려웠습니다. 보상과 제어 구조를 바꾸는 경험만큼, 실험 조건과 결과를 남기는 일의 필요성도 배웠습니다.
